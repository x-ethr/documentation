# Command Reference

This section documents the actual command surface in the live bot code.

## Roles

Commands generally fall into these groups:

- Organizer or server admin commands
- Captain commands
- Player commands
- ETHR owner-only DM commands

## Match Reporting

Two result entry paths exist:

- `/report-match` for winner captains
- `/elo match` for organizer-style manual reporting

## Matchmaking

Weekly matchmaking is configured with `/config` and generated with `/schedule generate` or the automatic weekly generator.

## Owner-Only DM Commands

These are not intended for normal guild members:

- `/activate-guild`
- `/list-active-guilds`
