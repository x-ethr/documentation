# `/edit-team`

Change your team's name or color — including two-color gradients.

## Options

- `name` `String` optional
- `color` `String` optional — hex code such as `#FFFFFF`, or `random`
- `color2` `String` optional — second color for a **gradient**; hex or `random`

## Notes

- This is a captain-facing command
- Providing `color2` gives your team role a gradient from `color` (or your current
  color) to `color2`
- Setting only `color` returns the role to a solid color and removes any gradient
- Only name changes are on cooldown; color edits are always free

<Callout type={"warning"}>
    Gradient role colors are a Discord boost perk — the server needs **Enhanced Role
    Colors** (Server Boost Level 2+). Solid colors work everywhere.
</Callout>
