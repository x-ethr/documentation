# `/activate-guild`

Owner-only DM command.

This command is not for normal guild users.

## Purpose

Activate a guild so it can use the bot.

## Options

- `guild_id` `String`

<Callout type="warning">
This command only works in a DM with the bot and only for the platform owner account.
</Callout>
