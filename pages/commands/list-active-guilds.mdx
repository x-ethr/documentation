# `/list-active-guilds`

Owner-only DM command.

This command is not for normal guild users.

## Purpose

List activated guilds with metadata.

The command returns:

- server name
- guild ID
- owner when available
- member count when available
- roster size
- enabled regions

<Callout type="warning">
This command only works in a DM with the bot and only for the platform owner account.
</Callout>
